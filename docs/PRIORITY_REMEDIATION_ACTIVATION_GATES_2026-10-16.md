## What this staged source release changes
- /admin/members is a member directory only; duplicate payment confirmation/rejection and direct official-unlock actions are removed from that screen. /admin/orders remains the canonical *current* desk, but is not yet transactionally safe.
- /admin/news and /admin/gallery no longer pretend local demo edits are persisted when live DB fails, and require a verified successful read before accepting writes.
- Admin dashboard shows unavailable totals instead of false zeroes on source errors.
- Season activation/Hall of Fame prestige no longer write old variable financial rate multipliers or partial loyalty_points upserts. Historical balances unchanged.
- Paid/rewarded orders cannot be deleted through the canonical order desk; destructive season deletion is blocked pending archival design.

## Release validation
Automated build/test success certifies this source revision only. It does not certify customer auth, RLS, payments, mobile UI, database data quality or refunds. Required production QA includes: fresh visitor, new/existing user, unauthenticated cross-user access, owner and least-privilege staff, concurrent confirmation/reversal, rejected and duplicated payment proofs, interrupted multi-table writes, opening/closed days, cancelled openings, historic balances, six distinct payers vs six cars, postponed refund, new vs old event terms, and page-specific network failure.
